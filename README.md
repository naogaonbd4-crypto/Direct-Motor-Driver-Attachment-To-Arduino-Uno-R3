# Direct-Motor-Driver-Attachment-To-Arduino-Uno-R3
exactly what the name says; meant to be compact. I made this for Science Olympiads Division C Electric Vehicle, where i needed a motor driver for my microcontroller (This pcb is not allowed to be used by OTHERS for the purpose of Science Olympiads according to rule 3C and rule 3KIII) If buying from PCBWAY, you can request for them to assemble it for you, but if not, a 10uf, .1uf, and a 2.2uf capacitor will be needed, as well as a drv8833PWP chip, a led, and sockets and pins.
It allows a max of 2 motors, and has pins 5,6,9,10 removed from the R3 to allow for the motors to be added. The power sources are connected as well
