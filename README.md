# Direct-Motor-Driver-Attachment-To-Arduino-Uno-R3
exactly what the name says; meant to be compact. It allows a max of 2 motors, and has pins 5,6,9,10 removed from the R3 to allow for the motors to be added. The power sources are connected as well
