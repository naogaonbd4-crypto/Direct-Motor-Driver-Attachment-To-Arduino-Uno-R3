# Direct-Motor-Driver-Attachment-To-Arduino-Uno-R3
exactly what the name says; meant to be compact. It allows a max of 2 motors, and has pins 5,6,9,10 removed from the R3 to allow for the motors to be added. The power sources are connected as well
<img width="687" height="353" alt="image" src="https://github.com/user-attachments/assets/aced299b-f591-41a5-a6f6-bd275b6bde79" />
here is the schematic, i organized it into boards: 
<img width="1273" height="821" alt="image" src="https://github.com/user-attachments/assets/a6da0b18-091d-4d77-a112-877e5c464ad1" />
The bottom connects to the Arduino Uno R3, while the top are the sockets to connect to R3 pins (except 5,6,9,10 which are already connected to the motors) and the OUT + EEP + ULT + VCC + GND pins of the motor driver
